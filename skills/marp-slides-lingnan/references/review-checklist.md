# 岭院 Slides 审阅检查清单（v2 严格版）

> 本清单基于实战复盘升级，**审阅子代理必须逐项严格对照**。每一条都对应过去一次踩坑——遗漏即可能产生溢出、孤字或视觉错乱。

## 使用方式

- **多维审阅 agents**（内容 / 格式 / 密度 / 视觉 / 中文规范）按对应章节逐项打勾
- **PNG 视觉自审子代理**（并行）严格执行第六章"PNG 视觉自审强制清单"，**逐页**输出结构化报告
- 任何"红色"项必须返回主代理修复，不能放过

---

## 零、强制硬约束（任何审阅都先看这里）

下列规则若违反，直接判 D（不及格），无需进入后续主观评分：

| 编号 | 规则 | 检查方法 |
|------|------|---------|
| H1 | 所有幻灯片标题用 `#`（h1） | 搜索 markdown 中所有 slide 起首是否为 `# `；用 `## ` 当 slide 标题即违反 |
| H2 | 字号基准 30px，padding 50/70/90/70 | 检查 frontmatter style 块是否含 `font-size: 30px` 与对应 padding |
| H3 | 表格 thead `!important` 链完整 | style 块必须含 `section table thead th { color: #fff !important; background: #AC1B20 !important }` |
| H4 | `footer: ' '`（一个空格）保留 | 不允许自定义 footer 文字，否则品牌图丢失 |
| H5 | `--theme-set` 与 `--allow-local-files` 都带 | 缺一岭院主题或品牌图加载失败 |
| H6 | 每页正文 ≤ 9 行（含自动换行展开） | 计算正文段落渲染后的总行数 |
| H7 | 每条 bullet ≤ 25 个汉字 | 防止单项折成 2 行 |
| H8 | 表格 ≤ header + 7 行 | 防止表后总结被挤出页面 |

## 一、内容检查

### 完整性
- [ ] 核心论点是否都已覆盖？
- [ ] 逻辑链条是否完整、承上启下清晰？
- [ ] 是否有必要的背景介绍？
- [ ] 结论是否清晰明确？

### 准确性
- [ ] 数据和事实是否正确？
- [ ] 引用是否准确标注？
- [ ] 术语使用是否一致？（同一概念全篇同一称谓，不要前面"LLM"后面"大语言模型"再后面"大模型"混用）

### 简洁性
- [ ] 是否有冗余内容可删除？
- [ ] 每个要点是否足够精简？
- [ ] 每条 bullet 起首是否加粗关键词，便于 0.5 秒扫读？
- [ ] 同义重复（如"大语言模型即 LLM"）是否只出现一次？

---

## 二、格式检查

### Marp 语法
- [ ] YAML frontmatter 完整（marp / theme / paginate / size / header / footer / style）？
- [ ] `---` 分页符正确？
- [ ] `footer: ' '`（一个空格）**不被改成自定义文字**？
- [ ] 完整 style 块包含：`section { font-size: 30px; padding: 50px 70px 90px 70px }`、thead 红头白字 `!important` 链、roadmap 组件 CSS？

### Markdown 格式
- [ ] **所有 slide 标题都用 `# `（h1），不用 `## `**？
- [ ] h2/h3 仅用于页内分级标题（如对比页的两栏小标题）？
- [ ] 列表格式统一（同页内全 `-` 或全 `1.`）？
- [ ] 粗体和 blockquote 使用得当？

### `<!-- _class: -->` 指令匹配
- [ ] 标题页 → `<!-- _class: title -->` ?
- [ ] 分隔页 → `<!-- _class: divider -->` ?
- [ ] 致谢页 → `<!-- _class: thanks -->` ?
- [ ] 总结页 **不要用** `<!-- _class: lead -->`（容易出孤字），改用普通 h1 + 内联格式

## 三、密度检查（重点 · 量化对照）

### 字号与画布参数

| 项 | 标准值 |
|----|-------|
| 基准字号 `section` | **30px** |
| 标题 h1 | `1.55em` ≈ 46.5px |
| 表格 | `0.82em` ≈ 24.6px |
| Padding | `50px 70px 90px 70px` |
| 可用内容区 | `1140 × 580 px` |

### 每页内容硬上限（与 SKILL.md 一致）

| 元素类型 | 满页硬上限 | 单元素上限 | 检查方式 |
|---------|----------|-----------|---------|
| 正文段落 | **9 行**（渲染后） | 单段 ≤ 2 行 | 估算自动换行后的总行数 |
| bullet 列表 | **9 项** | 单项 ≤ 25 个汉字 | 数项数 + 检查每项字数 |
| 表格 | **header + 7 行** | 单格 ≤ 18 字 | 数表格行数 |
| 数学公式块 | 每个按 2 行计 | 公式 + 注释 ≤ 6 行 | $$...$$ 块数 × 2 + 周围段落行数 |
| lead/居中页 | **6–7 行** | — | 居中样式段距更大 |
| roadmap 路线图 | 4 阶段 × ≤ 4 项 | 每项 ≤ 12 字 | 数 `<li>` 元素 |

### 内容密度分级

**绿色（通过）**：内容占页 60–80%，留白充足，单条信息可独立扫读
**黄色（警告）**：内容占 80–95%，建议精简但勉强可用，需在视觉自审中复核
**红色（必须修改）**：超 9 行硬上限 / 单项跨 2 行 / 表后总结被截 — 一律拒收

## 四、视觉检查

### 层次感

- [ ] 引用是否使用 blockquote（左侧红色边框）？

- [ ] 同一文档全篇基准字号一致？
- [ ] 列表符号是否统一？

### 岭院主题特有
- [ ] 顶部 4px 红色装饰线显示？
- [ ] 页脚灰条 + 校徽 + 院徽 + 中英文名 + AACSB 标志全部可见？

## 六、PNG 视觉自审强制清单（子代理使用）

> **本章是 PNG 视觉自审子代理的工作清单**。每个子代理负责 3–5 张 PNG，逐张严格按下列 8 项打分。

### 子代理输入
- 负责的 PNG 文件路径列表
- 本清单（即本章节内容）

### 8 项强制检查

| # | 检查项 | 不通过的表现 | 触发的修复建议 |
|---|-------|-------------|---------------|
| 1 | **标题红色（h1）** | 标题渲染为黑色或深灰 | 把 `## ` 改回 `# ` |
| 2 | **表头红底白字** | 表格首行白色背景或字看不见 | 检查 frontmatter 是否含 thead `!important` 链 |
| 3 | **末行完整可见** | 文字被页脚灰条截断、最后一行只露一半 | 减行或拆页（按 9 行硬上限） |
| 4 | **无孤字** | 段尾仅剩 1–2 字独占一行（如"破。"） | 改写措辞使段落整齐换行 |
| 5 | **列表项单行** | 单条 bullet 自动折成 2 行 | 精简到 25 字内或用"主题 — 解释"结构 |
| 6 | **内容占比 60–80%** | 过满（>90%，无留白）或过空（<40%，画面稀疏） | 拆页或合并 |
| 7 | **数学公式完整** | 公式溢出右边缘、上下溢出页面 | 拆公式或用更短记号 |
| 8 | **页脚品牌完整** | 校徽、院徽、AACSB 任一缺失 | 检查 `--allow-local-files` 与 `--theme-set` 路径 |

### 子代理报告格式（强制）

```
## 第 N 页（slide.NNN.png）
- 状态：✅ 通过 / ⚠️ 有问题（具体问题数）
- 检查 1（标题红色）：✅ / ❌ <如失败的具体描述>
- 检查 2（表头红底）：✅ / ❌ <如失败的具体描述>
- ...（仅列出失败项即可，通过项可省略）
- 修复建议：<具体可执行措施，引用本清单的"触发的修复建议"列>
```

### 子代理禁止事项

- **不要返回 PNG 原图给主代理**（节省主代理上下文）
- **不要给出主观艺术评价**（如"配色优雅"、"留白漂亮"），只做 8 项强制对照
- **不要在 1 张 PNG 上花超过 30 秒**——8 项是机械对照，不是创作

## 七、问题处理指南

### 溢出问题
```
问题：文字被页脚截断 / 末行不可见
解决（按优先级）：
1. 减少同义重复，删除冗余形容词
2. 把"X 是 Y 的原因有三"改成"三个原因"
3. 拆为多页
4. 启用更小字号（28px，但不要低于 26px）
```

### 表头空白
```
问题：表格首行（thead）渲染为白色背景，文字看不到
原因：自定义 section table 覆盖了主题 thead 样式
解决：在 style 块加入完整 !important 链：
  section table thead { background-color: #AC1B20 !important; }
  section table thead th { color: #fff !important; ... !important; }
```

### 标题不红
```
问题：某页标题是黑色，其他页是红色
原因：用了 `## 标题`（h2）
解决：改回 `# 标题`（h1）
```

### 孤字
```
问题：段尾"破。"独占一行
原因：lead 居中类放大段距 + 长段自动换行
解决：
1. 总结页改用普通 h1 + 内联格式（小标题 — 内容）
2. 改写句子使整段刚好满行不留尾
```

### 路线图盒子撑高错位
```
问题：某 phase 盒子比其他高出一截
原因：单 phase 列表项过多或单项过长
解决：每 phase ≤ 4 项，每项 ≤ 12 字
```

## 八、评分标准

| 评分 | 标准 |
|------|------|
| A（优秀） | 8 项 PNG 自审全过、零硬约束违规、内容密度黄绿之间 |
| B（良好） | PNG 自审无溢出/无孤字，但有 1–2 处密度黄色 |
| C（及格） | 有少量低风险问题（如某页略密但未溢出） |
| D（不及格） | 出现溢出 / 孤字 / 表头空白 / 标题不红 / 任一硬约束 H1–H8 违规 |

## 九、快速检查流程

1. **5 秒扫描**：每页快速浏览，感受密度
2. **硬约束验证**：先检查零章 H1–H8，任一违规直接拒收
3. **内容验证**：核对是否覆盖所有要点（一章）
4. **格式检查**：frontmatter style 块完整、所有标题 h1（二章）
5. **密度量化**：按三章表格逐页核行数（三章）
6. **PNG 视觉自审**：派多个子代理并行，按六章 8 项严格对照
7. **整体评估**：综合评分 + 结构化修复清单
