# Learn AI-Assisted Python Programming（Manning, 2023）

## 一句话定位

**“在编程入门阶段如何与 Copilot/ChatGPT 协作”** 的教学法书。
书的核心是 **the function design cycle with Copilot, augmented to include debugging**——
当本课程进入 Python 编程教学时（第 3 周），这本书的"提问-阅读-测试-改写"循环
可以直接作为 36 课时讲稿第 3 周“AI 辅助编程”节的方法论基础。

## 与本课程的契合点

- 教育者写给教育者：本书作者是 UCSD（Leo Porter）和 University of Toronto（Daniel Zingaro），
  长期研究编程教育（CS education），对"学生用 AI 会不会丧失基本能力"问题有数据支撑的回答。
  这与 36 课时讲稿第 1-2 周“AI 边界”的设计**思路高度一致**。
- 强调**测试与调试**而非"让 AI 帮你写完代码"。
- 把 Copilot 的"读懂代码 → 测试代码 → 修代码 → 让 AI 重写代码"做成可教的循环。

## 在本课程中的重点用法

- **第 3 周**：Python 入门 + AI 辅助编程，直接借鉴本书前 3 章的 prompt 模式。
- **第 4 周**：当切到 R 时，提示词模式可类比迁移。
- **第 17-18 周**：项目复盘时，让学生对照书中“debugging cycle”反思自己的 AI 使用习惯。

## 与 [Starting Data Analytics with GenAI](Starting_Data_Analytics_GenAI.md) 的差异

- 本书：函数级、编程入门、Copilot 行内补全为主。
- 另一本：项目级、数据分析、ChatGPT 对话为主。
- 课程应**两者都用**，对应"学编程"和"做项目"两个阶段。
- 详见 [synthesis/三本Python书定位对比](../synthesis/三本Python书定位对比.md)。
