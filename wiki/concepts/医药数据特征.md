# 医药数据特征

## 四个核心特征（来自 36 课时讲稿第 1 周）

1. **多源性**：临床检测、问卷、电子病历、公共数据库、转录组测序、单细胞测序、文献整理。
2. **高维性**：一个样本可能对应成千上万个基因 / 蛋白 / 代谢物。
3. **异质性**：不同来源、批次、平台、医院的数据难以直接合并。
4. **强解释性要求**：不能"代码跑通就算数"，必须回答**医学意义、可信度、是否会误导**。

## 数据形态光谱

```
临床指标表 ────── 长宽表/纵向数据 ────── 表达矩阵 ────── 单细胞 / 多组学张量
  低维 / 强语义     中维 / 时间维度     高维 / 弱语义         超高维 / 稀疏
   sample×var       sample×time×var    gene×sample          gene×cell×modal
```

不同形态对应**不同的分析重点**：

- 临床表 → 描述统计 + 假设检验 + 回归
- 纵向数据 → 重复测量 / 混合效应 / 生存分析
- 表达矩阵 → 差异表达 + 多重检验校正 + 可视化（heatmap / volcano）
- 单细胞 / 多组学 → 降维 + 聚类 + 轨迹推断

## 与生信数据的关系

生信数据（FASTA、FASTQ、SAM、BAM、VCF、count matrix）可以看作**医药数据的一支**：
- 共性：结构化、可重复、需统计校验
- 差异：医药数据更强调**临床语境与决策**，生信数据更强调**算法流程与上游处理**

本课程不深入生信上游（QC、比对、call variant），但要求学生理解
"为什么这类数据的分析流程长得这么长"——见 [RNA-seq 上游流程](RNA-seq上游流程.md)。

## 强解释性要求 → 对分析者的要求

- 知道**数据采集背景**：谁、为什么、怎么测的、有没有偏倚
- 知道**统计前提**：例如 t 检验要求正态、ANOVA 要求方差齐
- 知道**医学意义**：相对风险、绝对风险、NNT 不能混淆
- 知道**伦理边界**：去标识、知情同意、不可外传

## 课程位置

- **第 1 周**：导入本概念，建立学生的"数据分析非纯技术"意识。
- **第 8-10 周**：在假设检验 / 回归 / 分类章节反复回到本概念，强调结果解释。
- **第 17-18 周**：项目实战必须包含"数据来源与局限"自查清单。
