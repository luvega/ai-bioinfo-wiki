# 第 03 周：AI 辅助编程与 Python 快速入门 · PPT 大纲

## 教学目标

- 识别 Python 变量、列表、字典、条件和循环在医药数据处理中的作用。
- 能读懂一段 10 行以内的 Python 代码，并用小数据手算核验结果。
- 能使用 AI 解释代码、定位错误、生成测试用例，但不把 AI 输出当作最终结论。
- 建立本课程的 AI 编程红线：先理解问题，再生成代码，最后核验结果。

## 每页要点

### 2. 为什么药学学生要会读代码

- 药学数据分析常常从“判断规则”开始。
- 例如：某指标是否缺失、是否超过阈值、两组样本是否可比。
- 代码是把判断规则写清楚的一种方式。

### 4. 五个最小语法单元

- 变量：保存一个值。
- 列表：保存一组样本或指标。
- 字典：保存样本 ID 到分组、指标或标签的映射。
- 条件：表达是否缺失、是否异常、是否满足阈值。
- 循环：批量处理多个样本。

### 7-9. AI 协作三步

- 解释：让 AI 逐行说明代码做了什么。
- 调试：让 AI 根据错误信息定位原因，而不是直接重写一大段。
- 测试：让 AI 生成边界样本，再由学生手算或人工核验。

## 上机任务

给定：

```python
glucose = [5.2, 6.1, 4.9, None, 12.8, 5.7]
```

要求：

1. 过滤 `None`。
2. 计算均值。
3. 找出大于 7.0 的高风险值。
4. 写一条 AI 提示词，让 AI 解释你的代码是否处理了缺失值。

## 推荐提示词

```text
请逐行解释下面这段 Python 代码的作用，并指出它是否正确处理了 None 缺失值。请先解释，不要直接重写完整代码。
```

### 药学问题入口
药学学生需要把临床指标、样本分组和简单序列信息转化为可复核的规则，而不是把 Python 当作抽象语法课。

### AI协作边界
AI 可以解释代码、定位报错、生成测试用例；不能替代学生判断输入、输出、边界情况和医学含义。
