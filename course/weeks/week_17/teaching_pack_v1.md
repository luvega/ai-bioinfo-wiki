# Week 17 试讲包 v1

## 2 学时时间切分

| 时间 | 活动 | 教师动作 | 学生可提交产物 |
|---:|---|---|---|
| 0-10 min | 项目包导入 | 展示最低交付包和 rubric | 缺口自评 |
| 10-30 min | README 巡查 | 检查问题、数据、方法、运行顺序 | README 修订 |
| 30-50 min | 素材溯源 | 检查 `data_sources.md` 来源、字段、授权 | 来源表 |
| 50-70 min | AI 使用声明 | 检查 Prompt、用途、人工修改、不采纳理由 | AI statement |
| 70-90 min | Storyboard 互评 | 用图表证据边界表互评 1 页 PPT | 修改清单 |

## 课堂任务单

每组提交五件草稿：`README.md`、`data_sources.md`、`ai_use_statement.md`、`ppt_storyboard.md`、1 张核心图表或图表说明。

## 预期输出与参考答案

- README 应能让同学理解项目问题和阅读顺序。
- `data_sources.md` 必须写来源、字段、授权边界和待核验点。
- AI 使用声明必须写工具、Prompt、输出用途、人工修改和未采纳内容。
- Storyboard 每页必须有 action title、visual intent、evidence note、risk note。

评分点：README 20%，素材溯源 25%，AI 声明 20%，图表证据边界 25%，Git/GitHub 记录 10%。

## 常见误区

- 最终 PPT 很完整，但没有数据来源和字段说明。
- AI 生成了图注或代码，却没有声明。
- 只展示结果，不展示失败尝试和修改理由。

## 教师巡查清单

- 是否能追溯到原始教学数据或公开来源。
- 是否有 Git/GitHub 或等价版本记录。
- 是否明确图表支持什么、不支持什么。
- 是否把 AI 输出作为待核验材料而不是最终证据。

## AI 审计提示

```text
请按 README、数据来源、AI 使用声明、story board 和图表证据边界五项检查我的项目包。
只指出缺口和风险，不要替我补写最终结论。
```
