# 第 16 周：单细胞转录组可视化 · 授课脚本

## 开场

前两周我们讨论了 RNA-seq 的数据链条和差异表达分析。今天进入单细胞转录组可视化。bulk RNA-seq 测到的是一群细胞的平均表达，而单细胞 RNA-seq 试图观察每个细胞的表达状态。这个分辨率提升带来了新的机会，也带来了新的噪声和解释风险。

可以用一个简单问题导入：如果一个组织样本里有免疫细胞、上皮细胞和成纤维细胞，bulk RNA-seq 给出的表达变化可能是所有细胞混合后的平均值。我们看到某个基因上升，可能是某类细胞数量变多，也可能是每个细胞内表达变高。单细胞数据的价值，就是帮助我们拆开这种混合。

## 讲授主线

先讲单细胞流程。原始表达矩阵经过质控，去掉低质量细胞和异常细胞；然后进行 normalization，让细胞之间更可比；接着选择高变基因，抓住最能区分细胞状态的信号；再做 PCA，把高维表达压缩到主要变化方向；之后用 UMAP 或 t-SNE 做二维可视化；最后进行 clustering，并结合 marker gene 尝试注释细胞类型。

质控图是第一类重点。常见指标包括每个细胞检测到的基因数、UMI 总数和线粒体基因比例。基因数太低可能说明细胞质量差，线粒体比例太高可能提示细胞受损。这里要提醒学生，阈值不是固定真理，它依赖数据集和研究对象。

第二类重点是降维和聚类图。在 UMAP 图上，每个点通常代表一个细胞，颜色可以代表 cluster、样本来源或 marker 表达。UMAP 帮助我们观察结构，但它不是严格的定量距离图。两个 cluster 在图上看起来近，不一定能直接解释为生物学距离近。

第三类重点是 marker gene。某个 cluster 高表达某些 marker，可以支持细胞类型注释。但注释必须回到文献、数据库和研究背景。AI 可以帮我们整理 marker 候选和常见解释，但不能直接给出最终细胞类型结论。

## 课堂互动

展示一张 UMAP 示意图，问学生：每个点是什么？颜色是什么？cluster 是怎么来的？如果一个 cluster 高表达某个 marker，是否可以马上命名为某种细胞？通过这些问题，让学生意识到图形只是证据的一部分。

再展示一张 QC 指标图，让学生判断哪些细胞可能需要过滤，并说明理由。重点不是给出唯一阈值，而是训练他们说明判断依据。

## 上机/讨论引导

学生围绕一组单细胞可视化图写解读说明：先描述图上元素，再说明可能结论，最后列出不确定性和需要核验的点。AI 可以帮助整理流程，但提示词必须要求 AI 标注参数敏感性和人工核验点。

## 收束

单细胞可视化让我们看到细胞异质性，但图形不是结论本身。质控阈值、降维参数、聚类分辨率和 marker 选择都会影响解释。可靠的单细胞分析，不是把图画出来，而是能说明每一步为什么这样做，以及结论还需要哪些证据支持。
## 样板周授课补充

### 教学目标
让学生能读懂单细胞 QC、UMAP、cluster 和 marker 图，并知道这些图形不能直接等于生物学结论。

### 药学场景
围绕药物靶点是否只在某类细胞中表达、耐药细胞群是否存在，引出单细胞可视化价值。

### 核心数据结构
细胞 x 基因矩阵、QC 指标、降维坐标、聚类标签、marker gene 表达。

### 课堂任务
学生描述一张 UMAP 图上的点、颜色和 cluster，再列出至少两个不能直接下结论的原因。

### AI协作边界
AI 可辅助整理流程和 marker 候选；最终注释必须回到 marker 证据、文献、数据库和研究背景。

### 课后练习
写一段单细胞图形解读，必须包含参数敏感性和人工核验点。
