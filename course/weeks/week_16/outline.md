# 第 16 周：单细胞转录组可视化 · PPT 大纲

## 教学目标

- 区分 bulk RNA-seq 与 scRNA-seq 的数据含义。
- 描述单细胞分析的基本可视化流程。
- 能读懂 QC、UMAP/t-SNE、cluster 和 marker gene 图。
- 理解单细胞分析参数敏感性。
- 能使用 AI 辅助梳理流程，但不让 AI 直接给出细胞类型结论。

## PPT 结构

1. 标题页：单细胞转录组可视化
2. 导入问题：平均表达掩盖了什么
3. bulk RNA-seq 与 scRNA-seq 的区别
4. 单细胞数据为什么更稀疏、更噪声
5. 分析流程总览：QC 到 marker annotation
6. QC 图：基因数、UMI 数、线粒体比例
7. Normalization 与高变基因：为降维做准备
8. PCA：把高维表达压缩为主要变化方向
9. UMAP/t-SNE：用于看细胞状态结构
10. Clustering：算法分组不是最终生物学标签
11. Marker gene：从表达证据走向细胞类型注释
12. 参数敏感性：阈值、维度、分辨率都会改变结果
13. AI 协作：流程梳理可以，细胞注释要核验
14. 课堂练习：读一组单细胞可视化结果
15. 小结：图形帮助提出假设，不直接等于结论

## 课堂练习

给定一组单细胞可视化图，要求学生：

1. 判断是否存在低质量细胞群。
2. 解释 UMAP 上每个点和颜色代表什么。
3. 根据 marker 表达提出候选细胞类型。
4. 写出至少 3 个可能影响结果的参数。

## 推荐提示词

```text
请帮我梳理 scRNA-seq 从质控到 UMAP 聚类和 marker 展示的分析流程。请特别指出哪些参数会影响结果，以及哪些解释需要人工或文献核验。
```

## 风险提醒页

- UMAP 是可视化，不是严格距离度量。
- cluster 是算法结果，不自动等于细胞类型。
- marker 基因支持注释，但不单独构成结论。
- 参数变化可能导致不同聚类结果。

## 样板周质量区块

### 药学问题入口
药物作用可能只发生在特定细胞群，本周用单细胞图形理解细胞异质性和靶点表达位置。

### 核心数据结构
cell x gene matrix、QC 指标、PCA、UMAP/t-SNE、cluster、marker genes、annotation。

### 课堂任务
读取一组 QC、UMAP 和 marker 图，按“图上元素、可能结论、不确定性、待核验点”写解读。

### AI协作边界
AI 可以梳理流程和候选 marker；不能直接给出最终细胞类型注释或药物作用结论。

### 课后练习
选择一个 cluster，列出支持注释的 marker、反证风险和需要回查的数据库或文献。
