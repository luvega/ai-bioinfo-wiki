# ChatGPT

## 定位

通用对话式 LLM。本课程把它作为**项目级数据分析助手**使用，
对应 [Starting Data Analytics with GenAI](../sources/Starting_Data_Analytics_GenAI.md) 的工作流。

## 与 [GitHub Copilot](GitHub_Copilot.md) 的差异

详见 [Copilot 页面](GitHub_Copilot.md) §"与 ChatGPT 的差异"。一句话：
**Copilot 写代码、ChatGPT 想清楚要写什么**。

## 在课程中的典型用法

| 周 | 场景 |
|---|---|
| 1-2 | 解释概念、解释报错（不让它写代码） |
| 5-6 | 问"我的 messy data 有什么清洗思路" |
| 8-10 | 问"我的数据该用什么检验？前提是什么？" |
| 11-15 | 问"DESeq2 / Seurat 这一步为什么这么写？" |
| 17-18 | 项目报告改写、文献综述初稿 |

## 推荐替代

- **Claude / Gemini / Kimi / Qwen / DeepSeek** 在本课程语境下都可用。
- 教学时建议提醒学生：**模型不重要，方法重要**——本课程教的是协作流程，不是特定品牌。

## 红线

- 不要上传真实患者数据 / 含 PHI 的表格。
- 不要把 ChatGPT 输出作为正式结论。
- 不要假装是自己写的（学术诚信）：项目报告须**显式标注 AI 协作部分**。
