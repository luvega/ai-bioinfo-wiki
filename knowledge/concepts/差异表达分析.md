# 差异表达分析（DEA）

## 一句话

**找出在两个或多个条件下表达量显著不同的基因**——
本课程**第 15 周**的核心案例。

## 输入与输出

- 输入：
  - count matrix（行=基因，列=样本，[RNA-seq 上游流程](RNA-seq上游流程.md) 的产物）
  - metadata（样本→分组的对应表）
- 输出：
  - 每个基因一行：`log2FoldChange`、`pvalue`、`padj`、`baseMean`
  - 可视化：volcano plot、heatmap、PCA

## 三大 R 工具的差异

| 工具 | 统计模型 | 强项 | 弱项 |
|---|---|---|---|
| [DESeq2](../entities/DESeq2.md) | 负二项分布 + shrinkage | 鲁棒、文档好、生信社区默认 | 大数据慢 |
| edgeR | 负二项分布 + dispersion estimate | 性能好 | 学习曲线略陡 |
| limma + voom | 线性模型 + voom 转换 | 极快、支持复杂设计矩阵 | 对低 count 处理不如 DESeq2 |

**课程默认用 DESeq2**（与 AIDD Ch.9 一致）。

## 核心步骤（DESeq2）

```r
library(DESeq2)

dds <- DESeqDataSetFromMatrix(
  countData = counts,    # 整数 matrix
  colData   = metadata,  # data.frame，含分组列
  design    = ~ condition
)

dds <- DESeq(dds)
res <- results(dds, contrast = c("condition", "treated", "control"))
summary(res)
```

随后用 [ggplot2](../entities/ggplot2.md) 画 volcano、用 `pheatmap` 画 heatmap、用 `prcomp` 做 PCA。

## 统计前提与坑

- **数据必须是 count**（整数 / 未归一化），不要用 TPM/FPKM/RPKM 当输入。
- **多重检验校正**：默认是 BH（FDR）校正，不要用原始 p value 排序。
  → 这里需要 [ISLP Ch.13 Multiple Testing](../sources/ISLP.md) 的理论支撑。
- **样本量太少（n<3/组）**：DESeq2 结果可信度低；本课程教学数据请保证每组 ≥3。
- **批次效应**：不同测序批次需写进 design：`~ batch + condition`。
- **基因 ID 转换**：DESeq2 输出 Ensembl ID，画图前要转 gene symbol，见 AIDD Ch.9 §6。
