# AIDD 课程结构与内容整理（人写综述）

## 一句话定位

这是教师本人对 AIDD 课程**第一手字幕的二级整理**：把 11 章 71 节的内容
按"章节目标 / 课程清单 / 内容摘要 / 可整理成网站内容的结构"梳理了一遍，
并提出 **8 个建议重构模块**（生物编程总览 / Biopython / GUI 工具 / Bash 基础 /
NGS / Variant / R-DESeq2 / GitHub）。

引用 AIDD 时**优先看本文件，再回到原始字幕**——本文件已修正机翻误识、补全了缺失章节标记。
