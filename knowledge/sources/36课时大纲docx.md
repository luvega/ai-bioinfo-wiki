# 36 课时大纲（DOCX 原件）

## 一句话定位

这是教学大纲的**正式 docx 原件**，由教师本人撰写。
后续整理出的 [36 课时讲稿](36课时讲稿.md) 在其基础上扩写了每周的"讲稿话术 / 上机任务 / AI 提示词"。
当两者出现冲突时，**以本文件为准**（它是上报院系的版本）。

## 内容结构（按 docx 中的章节）

> 注：本知识库不复制 docx 全文，只列其骨架以供检索。如需细节，
> 请直接打开 `course/syllabus/36课时-AI前置调整版.docx`。

- 课程基本信息：课程名、学时、对象、先修
- 课程目标（知识 / 能力 / 育人）
- 教学内容与学时分配表（36 学时 × 18 周）
- 每周主要教学内容、育人元素、重点难点、备注（AI 边界）
- 考核方式
- 教材与参考资料
- 附录：AI 协作记录模板（如有）

## 与讲稿的差异

| 项 | docx 原件 | 讲稿 Markdown |
|---|---|---|
| 风格 | 表格 + 简明大纲 | 大段讲稿 + 上机任务 + Prompt |
| 用途 | 报备 / 公示 | 实际上课参考 |
| 是否含 AIDD 引用 | 否 | 明确点出每周可抽取的 AIDD 章节 |
