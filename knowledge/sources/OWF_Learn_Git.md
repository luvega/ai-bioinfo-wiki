## 课程使用边界

- Week 02：用于解释复现规范、Git 工作流、目录和命令行环境。
- Week 03：用于补充 AI 辅助编程前的 Git 与 shell 操作，不替代 Python 小数据主线。
- Week 17：用于综合项目协作、脚本化、故障排查和结果核验。
- Week 14/15：只作为 Bash/命令行辅助参考，不替代 AIDD 生信上游流程、DESeq2 或官方文档。
